## 📌 Project Overview
EasyShiftSchedule는 소규모 사업장의 직원 및 아르바이트생 근무 일정을
주간 단위로 쉽고 직관적으로 관리할 수 있도록 제작한
근무 일정 관리 프로그램입니다.

기존의 한글(HWP), Excel 등의 문서 프로그램을 이용한
근무표 작성 및 관리 방식에서 발생하는 불편함을 줄이고,
직원별 근무 일정과 근무 형태를 한눈에 확인할 수 있도록 구성했습니다.

PC 환경을 기반으로 근무표를 작성하고 관리할 수 있으며,
완성된 주간 근무표는 이미지로 다운로드하여
필요한 방식으로 직원들과 공유할 수 있도록 지원합니다.


### Project Information

- **Project Name** : EasyShiftSchedule
- **Project Type** : 개인 프로젝트
- **Target User** : 소규모 사업장 및 자영업자
- **Target Environment** : Windows PC
- **Current Version** : V1.0.0

## 🎯 Project Goal
기존 소규모 사업장에서는 직원 및 아르바이트생의 근무표를
한글(HWP), Excel 등의 문서 프로그램을 활용하여 직접 작성하고 관리하는 경우가 많았습니다.

하지만 근무 일정이 변경될 때마다 문서를 수정해야 하고,
완성된 근무표를 직원들에게 공유하는 과정에서도 번거로움이 발생할 수 있습니다.

EasyShiftSchedule는 이러한 근무 일정 관리의 불편함을 줄이고,
직원 및 아르바이트생의 근무 일정을 보다 쉽고 직관적으로 관리할 수 있도록 제작한
주간 근무 스케줄 관리 프로그램입니다.

특히 PC 및 프로그램 사용에 익숙하지 않은 50~60대 자영업자를 주요 사용자로 설정하여,
복잡한 기능이나 어려운 사용 방법을 최소화하고
누구나 쉽게 근무표를 작성하고 확인할 수 있는 사용자 경험을 제공하는 것을 목표로 했습니다.

### 주요 목표
- 직원 및 아르바이트생의 근무 일정을 쉽고 편리하게 관리
- 기존 문서 프로그램을 이용한 근무표 작성 및 수정의 번거로움 감소
- 주간 단위의 근무 일정을 한눈에 확인할 수 있는 직관적인 UI 제공
- PC 사용에 익숙하지 않은 사용자도 쉽게 사용할 수 있는 화면 구성
- 근무표를 이미지로 저장하여 직원들과 편리하게 공유할 수 있도록 지원


## ✨ Features
### 👥 직원 관리

- 직원 등록 및 정보 수정
- 직원별 고용 형태 관리
- 직원의 재직 / 퇴사 상태 관리
- 퇴사한 직원의 근무 일정 등록 제한

### 🕐 근무 형태 관리

- 오픈 / 미들 / 마감 / 휴무 등의 근무 형태 관리
- 근무 형태별 출근 시간 및 퇴근 시간 관리
- 근무 형태별 색상 구분

### 📅 주간 근무표

- 주간 단위의 근무 일정 확인
- 직원별 근무 일정 확인
- 이전 주 / 다음 주 이동
- 근무 형태에 따른 시각적 구분
- 동일한 근무 시간의 직원 자동 그룹핑

### 📝 근무 일정 관리

- 직원별 근무 일정 등록
- 근무 일정 수정 및 삭제
- 근무 형태를 이용한 일정 등록
- 고용 형태에 따른 휴무 일정 관리

### 🌓 반차 관리

- 고용 형태(직원)에 따른 반차 일정 관리
- 반차 적용 시 `출근 시간 ~ 반차` 형태로 근무 일정 표시
- 주간 근무표의 휴무 영역에 반차 직원 표시

### 🖼️ 근무표 이미지 다운로드

- 작성된 주간 근무표 이미지 다운로드
- 모바일 환경에서도 확인하기 쉬운 형태로 이미지 생성

## 🏗️ Architecture
EasyShiftSchedule는 React 기반의 프론트엔드와
NestJS 기반의 백엔드를 Electron으로 패키징하여
Windows Desktop Application 형태로 배포합니다.

### Electron 실행 구조

Electron 실행 시 백엔드(NestJS)를 먼저 실행하고,
백엔드가 정상적으로 준비될 때까지 로딩 화면을 표시합니다.

백엔드의 HTTP 연결이 확인되면 실제 React 화면을 로딩하여
사용자가 백엔드 초기화 과정에서 빈 화면을 보지 않도록 구성했습니다.

##### 직원 및 아르바이트

<p align="center"><img width="50%" height="425" alt="직원근무취소" src="https://github.com/user-attachments/assets/55dfd3a6-810b-4311-8fab-9af1f5d3c3d7" /><img width="50%" height="425" alt="알바근무취소" src="https://github.com/user-attachments/assets/03354fb9-9c4e-415d-8604-1ffbc1ca0c2e" /></p>

- 취소할 근무자를 선택한 후 취소할 근무 일정을 선택하고 근무 취소 클릭
- 근무 취소 확인 Dialog에서 확인 클릭
- 일정 취소 완료 시 일정 등록 완료 Snackbar 알림 표시
- 취소된 근무 일정은 근무표와 해당 근무자의 근무 일정 목록에서 자동으로 반영

### 🖼️ 근무표 이미지 다운로드
<p align="center">
<img width="100%" height="425" alt="일정표 다운로드" src="https://github.com/user-attachments/assets/d44b6fe5-cac6-4df9-ac3b-0e9efd70b803" /></p>

- 주간 근무표 작성 완료 후 일정 다운로드 클릭
- 다운로드 완료 시 근무표가 다운로드 되었습니다 Snack 알림 표시 출력
- 바탕화면에 근무표 다운로드 폴더가 자동 생성되며 다운로드한 이미지 저장
- 주간 근무표를 모바일 환경에서도 확인하기 편한 형태의 이미지로 저장

## 🔐 Security

본 프로젝트의 실제 소스 코드는 Private Repository에서 관리하며,
본 저장소는 프로젝트 소개 및 포트폴리오를 위한 Showcase Repository입니다.

- 데이터베이스 접속 정보 및 인증 정보는 Repository에 포함하지 않음
- 환경 변수 및 민감한 설정 정보는 `.env` 등을 통해 별도 관리
- 실제 사용자 데이터 및 운영 데이터는 공개하지 않음
- 본 Repository에는 프로젝트 소개, 기술 스택, 화면 및 개발 관련 정보만 공개
